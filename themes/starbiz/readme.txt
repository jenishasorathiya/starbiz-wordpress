== Description ==

StarBiz is a lightweight and performance-focused WordPress theme designed to help businesses establish a strong online presence. Built with clean code and full Elementor compatibility, StarBiz enables users to create professional websites without writing code.

Whether you're building a corporate website, startup landing page, agency portfolio, service-based business site, or company profile, StarBiz provides the flexibility and performance needed for modern web development.

== Installation ==

1. Upload the StarBiz theme folder to `/wp-content/themes/`.
2. Navigate to **Appearance → Themes**.
3. Activate **StarBiz**.
4. Install and activate **Elementor** for enhanced page-building capabilities.
5. Import demo content using the built-in demo importer.
6. Customize your website using Elementor and WordPress Customizer.

== Frequently Asked Questions ==

= Does StarBiz require Elementor? =

The theme works without Elementor, but Elementor is recommended to unlock all design and layout features.

= Is StarBiz WooCommerce compatible? =

Yes. StarBiz supports WooCommerce and can be used to create online stores.

= Is the theme responsive? =

Yes. StarBiz is fully responsive and optimized for desktops, tablets, and mobile devices.

= Does StarBiz support multilingual websites? =

Yes. The theme is translation-ready and compatible with multilingual plugins.

= Is StarBiz SEO friendly? =

Absolutely. The theme follows modern SEO best practices and semantic HTML standards.
