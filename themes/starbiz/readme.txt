A modern, lightweight, and fully customizable WordPress theme designed for businesses, agencies, and startups. Includes full Elementor support, responsive layouts, prebuilt templates, and flexible theme options.

== Description ==

StarBiz is a professional WordPress theme built with clean code and optimized for speed and SEO. It supports Elementor page builder, allowing you to easily create stunning layouts with prebuilt headers, footers, posts, widgets, and pages. Perfect for businesses, agencies, and startups wanting a modern web presence.

== Installation ==

1. Upload the StarBiz theme folder to the `/wp-content/themes/` directory.
2. Activate the theme through the 'Appearance > Themes' menu in WordPress.
3. Install and activate Elementor for full page builder compatibility.
4. Use the built-in demo importer to import prebuilt content (headers, footers, pages, widgets).
5. Customize the theme via WordPress Customizer and Elementor.
